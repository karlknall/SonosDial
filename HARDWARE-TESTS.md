# Reported hardware test

As of 7 November 2026, the user reported that version 1.0 “works”.

| Component | Reported setup |
|---|---|
| Operating system | Windows 11 Home |
| Speaker | Sonos Five |
| Router | AVM FRITZ!Box 7590 |
| Intended controller | ESP32-S3 DevKitC-1 N16R8 + KY-040 |

This is a general report from one user setup, not an independent laboratory test. Windows build, Sonos/FRITZ!OS version and performance measurements were not supplied.

Not separately confirmed: WPS success/timeout/cancel; multiple rooms/groups; every individual click/hold case; preservation of old settings during updates; long-duration operation. Windows 10 is a target, not a confirmed user test. These limitations are stated rather than presented as completed tests.

The localization package keeps the firmware byte-identical. English/German desktop screens, preference handling and error translation have additional software tests. No passwords, serial numbers or private IP addresses are required for this overview.
