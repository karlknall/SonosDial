# Original SonosDial identity

Original rotary-knob and sound-wave symbol, created for this project. No Sonos
corporate logo is used. MIT license (see ../licenses/MIT-SonosDial.txt).
sonosdial.svg is the editable vector master. PNG exports: 16–512 px; ICO contains
16/24/32/48/64/128/256 px PNG frames. installer-small.bmp is the installer header.
Regenerate with Build-Icons.ps1 on Windows. Logos are included in the app bundle.
