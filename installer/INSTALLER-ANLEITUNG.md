# Windows assistant

Run SonosDial-Setup-1.2.0-Windows.exe. Select English or German, then follow
Connect, Install, Connect Wi-Fi and Choose a room. Supported target: diymore
ESP32-S3 Mini, 8 MB flash / 8 MB PSRAM. No end-user Python or browser needed.
Use the mini board's single USB-C port. See README.md and docs/de/README.md.
